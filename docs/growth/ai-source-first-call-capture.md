# AI Source First-Call Capture

Prepared: 2026-08-31

Status: active first-call note standard

Ask these questions after the prospect has explained the business problem. Keep the wording conversational and do not make the source questions feel like a condition of help.

## Four required questions

1. Which AI platform did you use, such as ChatGPT, Gemini, Perplexity, or another tool?
2. About what did you ask it?
3. Where did Sequoia appear, first, second, later, or are you not sure?
4. Did the answer cite or link to a Sequoia page? If so, which page?

An optional fifth question can add useful context: What reason did the answer give for including Sequoia?

## HighLevel note template

```text
AI source capture
Platform:
Approximate question:
Recommendation position: first | second | later | unknown
Cited Sequoia URL:
Reason given, if volunteered:
Evidence status: prospect-reported, not identity-verified
Recorded by:
Recorded at:
```

## Rules

- Record the prospect's wording without rewriting it into a cleaner marketing query.
- Do not mark a visit, booking, inquiry, or lead as AI-originated from this note alone.
- Keep prospect-reported source evidence separate from browser referrer evidence.
- Do not record a full private AI conversation unless the prospect voluntarily provides it and storage is appropriate.
